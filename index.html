Код index.html зашит прямо в ссылку. Кто угодно откроет её — и увидит запущенную страницу без ручной вставки кода.

Ссылка не хранится ни на каком сервере — весь код лежит внутри неё самой. Очень длинный HTML может дать слишком длинную ссылку для некоторых мессенджеров.
